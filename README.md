# CodeAlpha Task 2: Unemployment Analysis with Python

## Project Overview
An Exploratory Data Analysis (EDA) project tracking unemployment trends across Indian states during 2020, highlighting the economic impact of the COVID-19 pandemic.

## Key Insights
1. **COVID-19 Impact:** A sharp spike in unemployment rates was observed during the Q2 2020 lockdown period.
2. **Regional Variations:** High variance in unemployment rates across different regions and area types.
3. **Core Correlations:** Analysis of relationships between labor participation rates and estimated employment.

## Tools Used
- **Python 3**
- **Pandas & NumPy** (Data Preprocessing & Aggregation)
- **Matplotlib & Seaborn** (Static Exploratory Visuals)
- **Plotly Express** (Interactive Hierarchical Charts)
